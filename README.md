# An Empirical Study of Synthetic Data Generators for Sequences

# Abstract

Synthetic Data Generators (SDGs) are increasingly used to produce
data for a wide range of tasks, and their effectiveness in preserv-
ing data utility for model development is well established. Prior
work has compared different types of generators, including those
used for tabular, image, and time-series data. However, fewer stud-
ies have examined how they perform on diverse sequences that
contain semantically ordered events (e.g., viewing content after
logging in to any followed activity). To fill this gap, we conducted
an empirical study of various SDGs across three types of sequences
that present different challenges for the generators. Our evaluation
emphasizes both statistical fidelity and data utility for downstream
model development. We observe distinct behaviors of SDGs when
operating under limited input data and when applied to hierar-
chical sequences. These findings suggest that new developments
of SDGs for sequences are required, while highlighting areas for
improvement.
